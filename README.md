# Python基础学习网站

从零开始学Python编程的入门学习网站，涵盖Python基础语法、数据类型、控制结构、函数与模块、常用算法和练习题目。

## 内容概览

- **首页**：学习指南和学习路径
- **基础语法**：Python简介、注释、变量、输入输出、运算符
- **数据类型**：字符串、列表、字典、元组
- **控制结构**：if-elif-else、for循环、while循环
- **函数与模块**：自定义函数、内置函数、标准模块
- **常用算法**：排序、查找
- **练习题目**：10道练习题（简单到困难）
- **学习大纲**：Python知识点要求对照表

## 技术栈

- 纯HTML/CSS/JavaScript，无需后端
- 响应式设计，支持移动端
