数据类型

字符串、列表、字典、元组

← 上一章 下一章：控制结构 →

📝 字符串 (String)

字符串是不可变的字符序列，常用于文本处理。

# 字符串创建
str1 = "Hello"
str2 = 'World'

# 索引和切片
s = "Python"
print(s[0])        # P
print(s[-1])       # n
print(s[0:3])      # Pyt
print(s[::-1])     # nohtyP - 反转

# 常用方法
print(s.upper())           # PYTHON
print(s.lower())           # python
print(s.strip())           # 去除空格
print(s.split())           # 分割
print(s.replace("P", "J")) # Jython

📋 列表 (List)

列表是可变的有序序列，Python中最常用的数据结构。

# 列表创建
nums = [1, 2, 3, 4, 5]
fruits = ["apple", "banana", "orange"]

# 基本操作
print(nums[0])          # 1
print(nums[1:4])        # [2, 3, 4]
print(len(nums))        # 5

# 添加元素
nums.append(6)          # 末尾添加
nums.insert(0, 0)       # 插入

# 删除元素
nums.remove(3)          # 删除值
nums.pop()              # 删除最后一个
del nums[1]             # 删除索引

# 列表推导式
squared = [x**2 for x in [1, 2, 3, 4, 5]]
# 结果: [1, 4, 9, 16, 25]

# 排序
nums.sort()             # 原地排序
sorted_nums = sorted(nums)  # 返回新列表

📖 字典 (Dictionary)

字典是键值对的无序集合，常用于数据存储和查找。

# 字典创建
student = {"name": "张三", "age": 18, "grade": "高一"}

# 访问字典
print(student["name"])    # 张三
print(student.get("age")) # 18

# 添加和修改
student["school"] = "XX中学"  # 添加
student["age"] = 19          # 修改

# 删除
del student["grade"]         # 删除键值对

# 遍历字典
for key, value in student.items():
    print(f"{key}: {value}")

# 字典方法
print(student.keys())        # 所有键
print(student.values())      # 所有值

🔢 元组 (Tuple)

元组是不可变的有序序列，常用于保护数据不被修改。

# 元组创建
point = (3, 4)
colors = ("red", "green", "blue")

# 访问元组
print(point[0])      # 3
print(colors[1:3])   # ('green', 'blue')

# 元组解包（重要！）
x, y = point
print(x, y)  # 3 4

# 多变量赋值
a, b, c = 1, 2, 3

# 交换变量
x, y = 10, 20
x, y = y, x  # x=20, y=10

# 元组与列表转换
nums = [1, 2, 3]
tuple_nums = tuple(nums)  # 转为元组
list_nums = list(tuple_nums)  # 转为列表

📊 数据类型总结

类型是否可变是否有序符号
字符串不可变有序"" ''
列表可变有序[]
元组不可变有序()
字典可变无序{}
